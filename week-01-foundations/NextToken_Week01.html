01
Foundations

The AI family tree

Why in the news

"AI", "GenAI" and "agentic AI" are now used interchangeably in headlines, job posts and board meetings. They are not the same thing, and an interviewer will notice if you mix them up.

Think of artificial intelligence as a set of nesting dolls. Each smaller doll is a more specific way of getting a computer to do something that looks intelligent.

The four rings, one sentence each

  • Artificial Intelligence (AI): any technique that lets a machine do something we would call intelligent. The term was coined for the Dartmouth workshop in 1956. A chess engine that follows hand-written rules is AI, but it does not learn.
  • Machine Learning (ML): instead of writing the rules, we show the computer examples and it finds the rules itself. The linear regression and decision trees you met in data analytics are ML.
  • Deep Learning (DL): ML using neural networks with many layers. It took off in 2012 when a network called AlexNet won the ImageNet image-recognition contest by a wide margin, trained on gaming GPUs.
  • Generative AI (GenAI): deep learning models that produce new content (sentences, pictures, music, code) rather than only labelling existing content.

Predict a label, or create something new?

This is the single most useful distinction for a data analyst. Most models you have built so far are discriminative: they look at an input and output a category or a number. Generative models learn what the data itself looks like, so they can produce fresh examples of it.

Curious mind asks

So is ChatGPT "AI" or "GenAI"?

Both, in the same way a Labrador is both a dog and a mammal. ChatGPT is an application built on a generative large language model (GPT), which is a deep-learning model, which is a kind of machine learning, which is a branch of AI. When it searches the web and runs code on its own to finish a task, that behaviour is agentic.

Quick recap
  • AI ⊃ ML ⊃ Deep Learning ⊃ GenAI.
  • Discriminative models label; generative models create.
  • Agentic AI is GenAI given goals, tools and memory.
  • Your analytics skills (data, features, evaluation) carry straight over.

03
Core concept

What is a large language model, really?

Why in the news

ChatGPT reported around 800 million weekly users in October 2025. Almost every GenAI product you will touch, from Copilot to customer-service bots, has an LLM at its centre.

A large language model is a very, very good autocomplete. Give it some text and it predicts which piece of text is most likely to come next. Then it adds that piece to the text and predicts again.

In plain English

Your phone keyboard suggests "you" after "thank". It learned that from your messages. An LLM did the same thing with a large share of the public internet, books and code, using a network with billions of adjustable dials. Because it learned from so much text, predicting the next word well means it had to pick up grammar, facts, reasoning patterns and even some common sense.

What makes it "large"?

Two things: the number of parameters and the amount of training data.

  • Parameters are the adjustable numbers (weights) inside the network. GPT-3 had 175 billion. If you printed each as a 10-digit number on paper, the stack would be taller than many mountains. Frontier labs no longer publish exact counts for their top models.
  • Training data is measured in tokens. Meta reported training Llama 3 on over 15 trillion tokens, roughly the text of tens of millions of books.
Under the hood

Formally, an LLM models the probability of a sequence by factoring it into next-token probabilities: P(w₁…wₙ) = Π P(wᵢ | w₁…wᵢ₋₁). This is called autoregressive generation: each output becomes part of the input for the next step. GPT stands for Generative Pre-trained Transformer, which describes exactly this: it generates, it was pre-trained on a large corpus, and it uses the Transformer architecture.

Curious mind asks

If it only predicts the next word, how can it solve a maths problem or write working code?

To predict the next word of a worked solution well, the model has to represent the steps that lead there. Researchers call abilities that appear only once models get big enough emergent abilities. Whether they are truly "reasoning" or very rich pattern-matching is still debated, and that debate is a good interview topic (we return to it in Week 8, on AGI).

Quick recap
  • LLM = next-token predictor trained on huge text.
  • Generation is a loop: predict, append, repeat.
  • Large = billions of parameters + trillions of tokens.
  • GPT = Generative Pre-trained Transformer.

Core concept

Tokens: the atoms of text

Why in the news

Every API bill, every "context window" limit and every rate limit is counted in tokens, not words. If you ever estimate the cost of a GenAI project, this is the unit you will use.

Models do not read letters or whole words. They read tokens: common chunks of text. "Unbelievable" might be split into "Un", "believ" and "able". Each chunk has an ID number in a fixed vocabulary.

Under the hood

Most LLMs use Byte-Pair Encoding (BPE) or a close cousin (WordPiece, SentencePiece). BPE starts from single bytes and repeatedly merges the most frequent adjacent pair into a new token until it reaches a target vocabulary size, typically 50,000 to 200,000 tokens. Frequent words become one token; rare words are built from pieces. That is why the model can handle words it has never seen, such as new product names.

The context window

The context window is the maximum number of tokens the model can look at in one go: your prompt, any documents, the conversation history and its own answer, all together. It is the model's working memory for a single request.

Curious mind asks

Why can't ChatGPT count the letter "r" in "strawberry"?

Because it never sees the letters. It sees something like "str", "aw", "berry" as three IDs. Counting characters inside a token is like asking you how many brush strokes are in a Chinese character you only know as a whole. Newer reasoning models handle this better by spelling the word out step by step first.

05
Core concept

Embeddings: meaning as a map

Why in the news

Embeddings power semantic search, recommendations, RAG chatbots and duplicate detection. For a data analyst they are the most immediately useful GenAI tool: they turn messy text into numeric features.

An embedding is a list of numbers that describes the meaning of a piece of text. Texts with similar meanings get similar numbers, so they sit close together on a map.

In plain English

GPS turns a place into two numbers (latitude, longitude), and places that are close in the world get close numbers. An embedding model turns a sentence into about 1,500 numbers, and sentences that mean similar things get close numbers. "My parcel never arrived" and "Delivery is missing" share no words, yet their embeddings sit next to each other.

How do we measure "close"?

Usually with cosine similarity: the cosine of the angle between two vectors. 1 means the same direction (same meaning), 0 means unrelated, and negative means opposite. You can compute it in one line of NumPy, and you will in the project.

Under the hood

cos(A, B) = (A · B) / (‖A‖ × ‖B‖). Embeddings come from a model trained so that related texts end up nearby, often with contrastive learning (pull matching pairs together, push random pairs apart). Popular embedding models include OpenAI text-embedding-3-small (Jan 2024), Cohere Embed, Google's Gemini embeddings and open models such as all-MiniLM-L6-v2 and BGE. They are stored and searched in vector databases such as Pinecone, Weaviate, Qdrant, Chroma, or Postgres with pgvector (Week 2).

Core concept

Attention and the Transformer

Why in the news

The 2017 paper "Attention Is All You Need" by eight Google researchers is one of the most cited papers in computing. GPT, Claude, Gemini, Llama and most image and video models are built on its idea.

Read this sentence: "The animal didn't cross the street because it was too tired." You instantly know "it" means the animal. Attention is the mechanism that lets a model make that same connection.

Try it · What does each word pay attention to?

Tap a word. The shading shows how strongly it attends to every other word (illustrative weights, modelled on real attention patterns).

In plain English

Older models read text left to right, one word at a time, and forgot the start of long sentences. A Transformer looks at all the words at once and, for each word, asks: "Which other words should I look at to understand this one?" It does that many times in parallel (multiple heads) and in many stacked layers. Because the work happens in parallel, it trains well on GPUs, which is why models could grow so large so quickly.

Under the hood: Query, Key, Value

For every token the model computes three vectors. The Query says "what am I looking for?", the Key says "what do I contain?", and the Value is "what I will pass on if chosen". Attention scores are the dot products of one token's query with every key, scaled and passed through softmax: Attention(Q,K,V) = softmax(QKᵀ / √dₖ)·V. Running several of these in parallel is multi-head attention. In a chat model, a causal mask stops each token from looking at tokens that come after it, so the model cannot cheat by peeking at the answer.

FamilyReads textGood atExamples
Encoder-onlyBoth directions at onceUnderstanding: classification, search, embeddingsBERT (2018), RoBERTa
Decoder-onlyLeft to rightGenerating text, chat, codeGPT, Claude, Llama, Gemini
Encoder-decoderEncode input, then decode outputTranslation, summarisationT5 (2019), original Transformer
Watch out

Attention cost grows with the square of the input length: doubling the context roughly quadruples the attention work. That is the main reason long context windows were hard and are still more expensive. Techniques like FlashAttention (2022) and sparse attention reduce the pain.

Core concept

How a model goes to school

Why in the news

The jump from GPT-3 (2020), which rambled, to ChatGPT (2022), which followed instructions politely, came mostly from better training after pre-training, not from a bigger model. "Explain RLHF" is one of the most common GenAI interview questions.

A chat model is trained in stages, much like a person: first it reads everything, then it learns from worked examples, then it learns from feedback on its own attempts.

In plain English

Stage 1 is a student who has read every book in the library but has never had a conversation. Ask "What is the capital of France?" and it might reply "What is the capital of Germany?", because lists of quiz questions are common online. Stage 2 is an apprenticeship where a tutor shows model answers. Stage 3 is the tutor grading the student's own attempts: "this answer is better than that one". Stage 4 is practice exams with an answer key.

RLHF in four steps

  1. The SFT model writes several answers to the same prompt.
  2. Human raters rank the answers from best to worst.
  3. A separate reward model is trained to predict those rankings, so it can score any answer.
  4. The chat model is optimised with reinforcement learning (originally an algorithm called PPO) to produce answers the reward model scores highly, while not drifting too far from its SFT self.
Under the hood: the alphabet soup

RLHF: Reinforcement Learning from Human Feedback, made famous by OpenAI's InstructGPT paper (Jan 2022).
Constitutional AI / RLAIF: Anthropic (Dec 2022). An AI critiques answers against a written set of principles, which reduces how many human labels are needed.
DPO: Direct Preference Optimization (Stanford, 2023). Skips the separate reward model and trains directly on preference pairs; simpler and widely used for open models.
RL with verifiable rewards: used for reasoning models such as OpenAI o1 (2024) and DeepSeek-R1 (2025). The reward is simply whether the final maths answer or code test is correct. DeepSeek's paper described an algorithm called GRPO.

Curious mind asks

Does ChatGPT learn from my chat while I'm talking to it?

No. The model's weights are frozen once it is released. It only "remembers" what is inside the current context window. Some products add a separate memory feature that saves notes about you and pastes them into future prompts, and providers may use conversations to train future models depending on your settings and plan. That is why company data policies matter (see Ch 9).

Hands-on concept

Temperature and the other dials

Why in the news

Ask the same question twice and you may get two different answers. That is by design. Knowing which dial controls it is essential when you build anything that must be repeatable, like a report generator.

At every step the model produces a probability for every possible next token. It does not always pick the top one. Temperature controls how adventurous the pick is.

Try it · Temperature playground

The cat sat on the mat

Under the hood

The model outputs raw scores called logits. They become probabilities through softmax: p(i) = e^(zᵢ/T) / Σ e^(zⱼ/T). Dividing by a small T exaggerates the gaps (the top choice wins almost always); a large T flattens them (unlikely words get a real chance). At T = 0 the model always takes the top token, which is called greedy decoding. Note that some newer reasoning models fix the temperature and do not let you change it.

In the real world

A bank summarising loan documents runs at temperature 0 with a strict output format, because two analysts must get the same summary. A marketing team generating ad headlines runs at 0.9 and asks for 20 options, because variety is the point. Same model, different dials.

Limits and risks

Hallucination, and other ways models fail

Why in the news

In February 2024 a Canadian tribunal ruled that Air Canada had to honour a refund policy its website chatbot had invented (Moffatt v. Air Canada). The company argued the chatbot was responsible for its own words. The tribunal disagreed.

A hallucination is a confident, fluent answer that is false. It is a side effect of how LLMs work: they are trained to produce the most plausible continuation, and plausible is not the same as true.

Why it happens

  • No fact database inside. Knowledge is stored as patterns in weights, so rare facts blur.
  • Trained to answer. Training data rarely contains "I don't know", so the model fills gaps.
  • Knowledge cutoff. The model knows nothing after its training data ends unless you give it search or documents.
  • Sampling. A higher temperature makes less likely, and sometimes wrong, tokens more likely.
RiskExampleMitigation

Curious mind asks

Will hallucinations ever go to zero?

Rates have dropped sharply with each generation, and grounding plus verification reduce them further. But a system that generates text by probability can always produce a plausible error. The professional stance: design the system so that errors get caught (citations, checks, human review for high-stakes output), rather than trusting any single answer.

Looking ahead

From chatbot to agent

Why in the news

Since late 2024 nearly every major lab has shipped "agents": software that can browse, click, write and run code, and call company systems to finish multi-step tasks. Gartner listed agentic AI as its top strategic technology trend for 2025.

A chatbot answers. An agent acts. Give an agent a goal, a set of tools and permission to loop, and it will plan steps, take actions, look at the results and keep going until the goal is met.

Five building blocks of every agent

BrainAn LLM that reasons and decides
ToolsFunctions it may call: search, SQL, email, APIs
MemoryShort-term context plus long-term store
PlanningBreaking a goal into steps, reflecting, retrying

The fifth is guardrails: permissions, budgets, and human approval for anything irreversible. Andrew Ng popularised four "agentic design patterns" in 2024 that map onto this: reflection, tool use, planning and multi-agent collaboration. We cover each in Weeks 5 and 6.

Curious mind asks

Is an agent the same as AGI?

No. An agent is a design pattern around today's models, and it can be narrow (an agent that only reconciles invoices). AGI, artificial general intelligence, means a system that matches humans across most cognitive tasks. There is no agreed definition or test yet. Week 8 covers the main definitions and how to discuss them in an interview without hype.

Career

Interview corner: 20 questions from this week

Interviewers for analyst, data-science and AI-engineer roles now open with GenAI fundamentals. They are testing whether you understand the mechanism and the trade-offs, not whether you memorised a definition.

The four-beat answer frame
1 · DefineOne crisp sentence in correct terms.
2 · AnalogyOne everyday comparison that proves you understand it.
3 · ExampleA real product, company or date.
4 · Trade-offA limitation, cost or "it depends". This is what seniors listen for.

Tap a question to reveal a model answer. Say your own answer out loud first, then compare.

Q01What is Generative AI, and how is it different from traditional machine learning?Basic

Define: GenAI models learn the patterns of their training data well enough to create new content: text, images, code, audio. Traditional (discriminative) ML maps an input to a label or number. Analogy: a critic who rates paintings versus an artist who paints new ones. Example: a churn model flags at-risk customers; an LLM drafts a tailored retention email for each. Trade-off: generative outputs are harder to evaluate because there is no single correct answer, so you need rubrics, human review or LLM-as-judge.

Q02How does a large language model generate a response?Basic

It tokenises the prompt, runs the tokens through a stack of Transformer layers, and outputs a probability for every token in its vocabulary. A decoding strategy (greedy or sampling with temperature/top-p) picks one token, which is appended to the input, and the loop repeats until a stop token or length limit. This is autoregressive generation. Trade-off: output time and cost scale with the number of output tokens, so long answers are slower and pricier.

Q03What is a token, and why should a business care?Basic

A token is a sub-word chunk from the model's fixed vocabulary; in English one token is roughly four characters or three-quarters of a word. APIs bill per input and output token, context limits are in tokens, and rate limits are in tokens per minute. So a cost estimate is: requests × (avg input tokens × input price + avg output tokens × output price). Also mention that many non-English languages need more tokens per sentence, which raises cost.

Q04What is a context window, and what happens when you exceed it?Basic

It is the maximum number of tokens the model can consider in one request, including the system prompt, history, documents and its own output. Exceed it and the API errors out, or the application has to truncate or summarise older content. Bigger windows help, but cost and latency rise and models can overlook information in the middle of long inputs. For large knowledge bases you retrieve only the relevant chunks (RAG) instead of pasting everything.

Q05Explain embeddings and cosine similarity with a business use case.Intermediate

An embedding is a dense vector that represents meaning; semantically similar texts produce vectors pointing in similar directions. Cosine similarity measures the angle between them: 1 means same meaning, about 0 means unrelated. Use case: embed 50,000 support tickets, cluster them with K-means to find the top complaint themes, and use nearest-neighbour search to route new tickets to the team that solved similar ones. Trade-off: embeddings from different models are not comparable, and you need to re-embed everything if you change models.

Q06What is a Transformer, and why did it replace RNNs and LSTMs?Intermediate

The Transformer (Google, "Attention Is All You Need", 2017) processes all tokens in parallel using self-attention instead of reading one step at a time. That makes training massively parallel on GPUs and lets the model link distant words directly, so it captures long-range context better than RNNs, which suffered from vanishing gradients. Trade-off: attention cost grows quadratically with sequence length.

Q07Walk me through self-attention: what are Query, Key and Value?Advanced

Each token's embedding is projected into three vectors. The query represents what the token is looking for, the key what it offers, the value the information it passes on. Scores are dot products of a query with all keys, divided by √dₖ for numerical stability, then softmaxed into weights; the output is the weighted sum of values. Multi-head attention runs several of these in parallel so different heads can track different relationships (syntax, coreference, position). In decoders, a causal mask blocks attention to future tokens.

Q08BERT versus GPT: what is the difference?Intermediate

BERT (Google, 2018) is encoder-only and bidirectional: trained to fill in masked words using context on both sides, it is strong at understanding tasks such as classification and search. GPT is decoder-only and left-to-right: trained to predict the next token, it is built for generation. Today, decoder-only models dominate chat and agents, while BERT-style encoders are still common for cheap, fast embeddings and classification.

Q09What is the difference between pre-training and fine-tuning?Basic

Pre-training is the expensive first stage: self-supervised next-token prediction on trillions of tokens, which produces a general base model. Fine-tuning continues training on a much smaller, task-specific dataset (instructions, a company's support tickets, a style) to specialise behaviour. Analogy: a general degree versus on-the-job training. Trade-off: fine-tuning teaches style and format well but is a poor way to add fresh facts; RAG is usually better for knowledge.

Q10Explain RLHF. How is DPO different?Advanced

RLHF: collect several model answers per prompt, have humans rank them, train a reward model on those rankings, then optimise the LLM with reinforcement learning (classically PPO) to maximise reward while a KL penalty keeps it close to the original. It made InstructGPT and ChatGPT helpful. DPO (2023) skips the reward model and RL loop, directly adjusting the model to prefer chosen over rejected answers with a simple classification-style loss; it is cheaper and more stable. Risk in both: reward hacking and sycophancy, where the model learns to please rather than be right.

Q11What does temperature do? When would you set it to zero?Basic

Temperature rescales the logits before softmax. Low temperature sharpens the distribution (more deterministic); high temperature flattens it (more diverse, more errors). Set it near 0 for extraction, classification, SQL generation, or any output that must be consistent and auditable. Use 0.7 to 1.0 for brainstorming. Note that even at 0, outputs may vary slightly across runs due to hardware-level non-determinism.

Q12Top-k versus top-p sampling?Intermediate

Top-k samples only from the k most likely tokens. Top-p (nucleus) samples from the smallest set whose cumulative probability exceeds p, so the candidate pool grows when the model is unsure and shrinks when it is confident. Top-p adapts better, which is why it is the more common API parameter. Usually tune either temperature or top-p, not both.

Q13What is hallucination, and how would you reduce it in production?Intermediate

A fluent, confident but false output, caused by the model generating plausible text without a built-in fact check. Mitigations in layers: ground answers in retrieved documents (RAG) and require citations; lower temperature; constrain outputs with schemas; let the model say "I don't know"; use tools for calculations and lookups; add automated checks (citation exists, numbers match the source); and keep human review for high-stakes outputs. Cite Mata v. Avianca (2023) or Air Canada (2024) as real costs of skipping these steps.

Q14A bank asks: open-weight or closed model? How do you decide?Advanced

Frame it as a decision matrix: data residency and regulation (can customer data leave our network?), quality on our own evaluation set, total cost (per-token fees versus GPUs plus engineers), latency, need for fine-tuning, and vendor risk. Banks often start with a closed model under enterprise terms or a private cloud deployment for speed, and use open-weight models for sensitive or high-volume workloads. The honest answer is "benchmark both on our task", and say how you would build that benchmark.

Q15What is a knowledge cutoff? How do chat products answer questions about today's news?Basic

The knowledge cutoff is the date after which the training data stops, so the model has no built-in knowledge of later events. Products work around it with tools: a web-search tool fetches current pages and the model answers from those results, ideally with citations. This is retrieval at runtime, the same idea as RAG.

Q16What is the difference between generative AI and agentic AI?Intermediate

Generative AI produces content in response to a prompt. Agentic AI wraps a generative model in a loop with a goal, tools, memory and planning so it can take actions over many steps: reason, call a tool, observe the result, decide the next step (the ReAct pattern). Example: answering "what is churn?" versus "investigate why churn rose in March and email me a chart". Trade-off: more autonomy means more risk, so agents need permissions, budgets, logging and human approval for irreversible actions.

Q17What is a foundation model?Basic

A term popularised by Stanford researchers in 2021 for a large model trained on broad data that can be adapted to many downstream tasks (via prompting, fine-tuning or RAG). GPT, Claude, Gemini and Llama are foundation models. The business implication: companies rarely train from scratch; they build on a foundation model.

Q18Why do LLMs struggle with arithmetic or counting letters?Intermediate

Tokenisation hides individual characters and splits numbers into irregular chunks, and the model predicts digits as text rather than executing an algorithm. Fixes: let the model reason step by step, or better, give it a code-execution or calculator tool. In analytics, always have the model write pandas or SQL and run it, rather than trusting its mental maths.

Q19Scenario: your manager wants to "use ChatGPT on our 20,000 customer reviews". What do you do?Scenario

Clarify the business question first (top complaints? product defects? weekly trend?). Check data policy: can reviews go to an external API, and does anything need redacting? Estimate tokens and cost. Prototype on a labelled sample of 200 reviews: embeddings plus clustering to discover themes, then an LLM at low temperature to tag sentiment, theme and urgency in strict JSON. Measure accuracy against human labels, iterate the prompt, then scale with batching and caching, and present a dashboard with example quotes. This is exactly this week's project, so you can say "I have built this".

Q20Scenario: how would you measure whether a GenAI chatbot actually helps the business?Scenario

Define success metrics before launch: containment rate (resolved without a human), resolution time, customer satisfaction, escalation rate, and quality measures such as answer accuracy on a sampled audit and the hallucination rate. Run an A/B test or phased rollout against the existing process. Track cost per resolved conversation. Watch for counter-metrics: repeat contacts and complaints. Klarna's 2024 numbers and its 2025 rebalance toward human agents are a good example to cite.

Step 02 · Token audit and cost projection

import tiktoken
enc = tiktoken.get_encoding("o200k_base")   # tokenizer used by GPT-4o-family models
df["n_tokens"] = df["review"].apply(lambda t: len(enc.encode(t)))

PROMPT_OVERHEAD = 350      # system prompt + instructions, tokens per call
OUTPUT_TOKENS   = 60       # expected JSON answer size
PRICE_IN, PRICE_OUT = 0.15, 0.60   # USD per 1M tokens: check current pricing

monthly = 10_000
cost = monthly * ((df.n_tokens.mean() + PROMPT_OVERHEAD) * PRICE_IN
                  + OUTPUT_TOKENS * PRICE_OUT) / 1e6
print(f"Avg tokens/review: {df.n_tokens.mean():.1f} | Est. monthly cost: ${cost:,.2f}")

Step 03–04 · Embeddings, similarity and themes

from sentence_transformers import SentenceTransformer
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA
import numpy as np

model = SentenceTransformer("all-MiniLM-L6-v2")
X = model.encode(df["review"].tolist(), normalize_embeddings=True)  # shape (n, 384)

# cosine similarity = dot product when vectors are normalised
q = model.encode(["my order never arrived"], normalize_embeddings=True)[0]
df["sim_delivery"] = X @ q
print(df.nlargest(5, "sim_delivery")[["review", "sim_delivery"]])

df["cluster"] = KMeans(n_clusters=6, n_init=10, random_state=42).fit_predict(X)
df[["pc1", "pc2"]] = PCA(n_components=2).fit_transform(X)

Step 05 · Structured LLM labelling at temperature 0

from openai import OpenAI
import json, os
# OpenAI if available, else Gemini's free tier via its OpenAI-compatible endpoint
if os.getenv("OPENAI_API_KEY"):
    client, MODEL = OpenAI(), "gpt-4o-mini"
else:
    client = OpenAI(api_key=os.getenv("GEMINI_API_KEY"),
        base_url="https://generativelanguage.googleapis.com/v1beta/openai/")
    MODEL = "gemini-2.5-flash"

SYSTEM = """You label customer reviews for an electronics retailer.
Return ONLY JSON: {"sentiment": "positive|neutral|negative",
"theme": "delivery|quality|battery|price|support|usability",
"urgency": 1-5, "summary": "max 12 words"}.
If unsure, choose the closest theme. Never invent facts."""

def label(review: str) -> dict:
    r = client.chat.completions.create(
        model=MODEL,
        temperature=0,                                  # repeatable (Ch 8)
        response_format={"type": "json_object"},          # structured output
        messages=[{"role": "system", "content": SYSTEM},
                  {"role": "user", "content": review}])
    return json.loads(r.choices[0].message.content)

Glossary and one-page cheat sheet

Agent
An LLM in a loop with goals, tools and memory that takes actions.
AGI
Artificial general intelligence: human-level ability across most cognitive tasks. No agreed definition.
Attention
Mechanism that lets each token weigh information from other tokens.
Autoregressive
Generating one token at a time, each conditioned on all previous tokens.
Base model
A pre-trained model before instruction tuning; it continues text.
BPE
Byte-Pair Encoding, the common method for building a token vocabulary.
Context window
Maximum tokens a model can process in one request.
Cosine similarity
Angle-based closeness of two vectors; 1 = same direction.
DPO
Direct Preference Optimization; preference tuning without a reward model.
Embedding
A vector of numbers representing meaning.
Emergent ability
A skill that appears only once models pass a certain scale.
Fine-tuning
Further training a model on a smaller, task-specific dataset.
Foundation model
A large general model adapted to many tasks.
GAN
Generative Adversarial Network (2014): generator versus discriminator.
Greedy decoding
Always taking the most likely next token (temperature 0).
Grounding
Tying a model's answer to supplied sources.
Hallucination
Fluent, confident output that is false.
Inference
Running a trained model to get outputs (as opposed to training it).
Knowledge cutoff
The date the training data ends.
Logits
Raw scores the model outputs before softmax.
LLM
Large language model; a Transformer trained to predict tokens.
MCP
Model Context Protocol (Anthropic, Nov 2024): open standard for connecting tools and data to models.
Multimodal
Handles more than one data type: text, image, audio, video.
Open weights
Model parameters you can download and run yourself.
Parameters
The learned numbers (weights) inside a network.
Pre-training
The first, largest training stage on broad unlabelled data.
Prompt
The input text and instructions given to a model.
Prompt injection
Malicious instructions hidden in content a model reads.

Retrieval-Augmented Generation: fetch relevant documents, then answer from them (Week 3).

Reinforcement Learning from Human Feedback.

Turns logits into probabilities that sum to 1.

Temperature
Controls randomness of sampling.

A sub-word unit of text; ≈ ¾ of an English word.

Sample only from the most likely tokens covering probability p.

Attention-based neural architecture (Google, 2017).

Database built to store and search embeddings.
