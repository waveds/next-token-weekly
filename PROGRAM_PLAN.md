# Program plan: Generative AI and Agentic AI in 8 weeks

A weekly program for data analytics learners who already know the basics of GenAI (what a model is, what OpenAI does). Each week publishes one newsletter issue (about 30 pages) and one industry project.

| | |
|---|---|
| **Duration** | 8 weeks, 30 Nov 2026 to 18 Jan 2027 |
| **Cadence** | One issue every Monday |
| **Each issue contains** | Concepts in plain English and technical terms, dated timeline, diagrams, real-world case studies, interview questions with model answers, a quiz, and a project |
| **Each project contains** | Jupyter notebook, sample data, README, resume bullet template |

## Phase 1 · Begin the journey (Weeks 1 to 3)
The vocabulary and the core mechanics.

| Week | Date | Issue | Topics | Project |
|---|---|---|---|---|
| 1 | 30 Nov 2026 | How machines learned to write | AI family tree, history 1950 to now, LLMs, tokens, embeddings, attention, training (SFT, RLHF), temperature, hallucination, model landscape, intro to agents | ReviewLens: GenAI customer feedback analyser |
| 2 | 7 Dec 2026 | Talking to models | Prompt engineering patterns, few-shot, chain of thought, system prompts, structured output, function calling, embeddings deep dive, vector databases | Semantic FAQ search for a telecom company |
| 3 | 14 Dec 2026 | Giving models a memory | RAG end to end: chunking, retrieval, re-ranking, grounding, citations, RAG evaluation | HR policy assistant over PDFs |

## Phase 2 · The end-to-end journey (Weeks 4 to 6)
From a raw model to a working, evaluated product, then to agents.

| Week | Date | Issue | Topics | Project |
|---|---|---|---|---|
| 4 | 21 Dec 2026 | Making a model yours | Fine-tuning, LoRA, distillation, evaluation sets, LLM-as-judge, guardrails, cost and latency, LLMOps | Support-ticket classifier: fine-tuned small model vs prompted large model |
| 5 | 28 Dec 2026 | From chat to action | Agentic AI: tools, the ReAct loop, planning, memory, reflection, human-in-the-loop | SQL data-analyst agent |
| 6 | 4 Jan 2027 | Teams of agents | Multi-agent patterns, orchestration frameworks, MCP (Nov 2024), A2A (Apr 2025), agent security and prompt injection | Market-research agent crew |

## Phase 3 · The frontier, right now (Weeks 7 to 8)
What companies are shipping today, and where it is heading.

| Week | Date | Issue | Topics | Project |
|---|---|---|---|---|
| 7 | 11 Jan 2027 | AI at work today | Reasoning models, multimodal AI, computer-use and coding agents, deep research, industry case studies (banking, healthcare, retail, manufacturing, India) | Autonomous BI-report agent using MCP |
| 8 | 18 Jan 2027 | AGI, safety and your career | AGI definitions and debates, scaling laws, alignment, EU AI Act, IndiaAI Mission, responsible AI, mega interview question bank | Capstone project and portfolio review |
